# Site statique - Réflexologie plantaire

Fichiers générés : pages statiques en français.

Structure :

- `index.html` : page d'accueil
- `about.html` : à propos
- `localisation.html` : localisation
- `contact.html` : contact (formulaire statique)
- `css/style.css` : styles
- `assets/` : placez vos images ici (logo a fleur de pied.jpg, logo.png (fédération), waiting_room.jpg, portrait.jpg, formation.jpg, room1.jpg, beach.jpg, card.jpg)

Pour voir le site localement, ouvrez `index.html` dans votre navigateur ou servez le dossier `stage-site` avec un serveur local (ex. `python -m http.server`).

Remarques :
- Le formulaire est statique (action="#"). Je peux ajouter une intégration e-mail ou backend si souhaité.
- Couleurs choisies : association terracotta et vert (préférence utilisateur).
